# 06 — User docs

**What to build:** A user can learn `/goal` from shipped docs in product voice: what a Goal is, how to set / pause / resume / clear / complete, that Stop Pauses, and that work continues if they leave.

**Blocked by:** 05 — Goal UX

**Status:** ready-for-agent

- [ ] User-facing docs describe `/goal` without repo paths, harness names, or ticket numbers
- [ ] Maintainer glossary defines Goal, Objective, Continuation, Pause, Complete, Clear, Blocked, Usage-limited using the same language as `CONTEXT.md`
- [ ] Docs state that Settle / Snooze / a closed client do not Pause, and that `/goal` is T3’s, not a provider command
- [ ] Reverse states are documented: Pause/Resume, Clear, Complete

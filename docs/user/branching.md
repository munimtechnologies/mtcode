# Branch a conversation

Claude Code and Codex threads can branch from any completed assistant response. Open the response
actions and choose **Fork from this response**. On web and desktop, the action appears when you
hover or focus the response footer. On mobile, use the branch icon beside Copy.

T3 Code opens the fork as a new thread and leaves the original unchanged. The new thread includes
the conversation through the selected response, including tool calls and tool results, and can be
continued independently.
